# Утверждённые веб-копии HSK Course 1

Здесь собраны локальные автономные HTML-копии опубликованных страниц учебника 3–7. Откройте `index.html`, выберите страницу и переключите язык кнопкой **English** в верхней панели.

Для каждой страницы приложен локальный CSS и используемые изображения. Шрифты Google Fonts подключаются по сети; без сети браузер использует системные шрифты. Переключение языков и текстовые слои встроены в HTML.

`manifest.json` содержит ID конверсии, дату публикации и число английских текстовых слоёв для сверки с платформой. Копии созданы из текущих страниц FS и опубликованы только в локальную платформу. Папка подготовлена для передачи Cloud; синхронизация и отправка в Cloud не выполнялись.
