# Учебник HSK 1

Веб-копии из текущей локальной FS. Страницы 1–11 экспортируются из сохранённых HTML, без повторной конвертации. Исходная нумерация сохранена. CSS, изображения и используемые аудиофайлы скопированы с относительными путями. Переключатели и встроенный runtime сохранены. Внешние шрифты загружаются по сети; сервисные запросы к платформе требуют работающего сервера. Ранее скопированные последующие страницы не удаляются. Откройте index.html.
