# WB HSK 1

Веб-копии всех сохранённых страниц из текущей локальной FS, без повторной конвертации. Экспорт не означает подтверждение точного сходства или полной языковой готовности. Исходная нумерация сохранена. CSS, изображения и используемые аудиофайлы скопированы с относительными путями. Переключатели и встроенный runtime сохранены. Внешние шрифты загружаются по сети; сервисные запросы к платформе требуют работающего сервера. Откройте index.html.
