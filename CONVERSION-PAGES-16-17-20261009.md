## Улучшения общего алгоритма

- Измерение пронумерованных фонетических упражнений по OCR-координатам, общий базис строк и отдельные интерактивные слоги. Нейтральный тон определяется для конкретного элемента, а не переносится из другого вхождения слова.
- Фотографии с подписями выделяются по рамке и границе фото/подписи. WB17: четыре самостоятельные карточки, подписи — HTML, с переводом и озвучкой.
- Родные и переведённые диалоги получают отдельную геометрию; нижний номер страницы остаётся закреплённым. Сохранены переносы китайского текста из исходника.
- Различаются одинаковые иероглифы с разным пиньинем (например, dōngxī и dōngxi). В WB17 опубликованы все 34 словарные позиции. Прежний лимит 20 для публикации FS заменён защитным лимитом 200; лимит AI-черновиков остался прежним, структура каждого слова проверяется.
- Переводы переиспользуются только при однозначном совпадении исходного текста и русского перевода. Ревизия не должна терять ранее имеющийся KZ; публикация требует полного KZ.
- Инвентаризация, обновление и аудит находят материалы по библиотеке, без привязки только к HSK1. Это основа проверки следующего курса после его загрузки.
- Массовый сценарий повторяет временно заблокированную Windows запись (EPERM/EBUSY) до трёх раз.
- Доступно безопасное обновление сохранённых страниц без повторного OCR, с отдельной ревизией и откатом.

## Правила следующего прохода

Работать только по запросу пользователя с очередными исходными страницами. Номера — порядковые страницы загруженного файла, включая вводные. Перед публикацией проверять исходник/рендер, таблицы и каждую ячейку, интерактивность, произношение тонов, RU/EN/KZ и словарь страницы. Новые UI-блоки — только по отдельной команде. Ошибку устранять в общем алгоритме и фиксировать регрессионным случаем; процент совпадения пикселей не заменяет эти проверки.

После загрузки HSK5 через локальную FS сначала проверить метаданные курса, тип учебник/WB, порядковую нумерацию и языковой контракт. Никакой автоматической загрузки в Cloud в этой задаче нет.

Для контрастов нейтрального/полного тона несколько аудио составлены из изолированных слогов: происхождение и хеши описаны в contrast-word-recordings.json. Это учебные записи, не доказательство естественного непрерывного произношения; аудио остаётся предметом проверки преподавателем.
