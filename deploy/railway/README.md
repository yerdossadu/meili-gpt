# Railway: учебная платформа для тестирования

Сайт: https://meili-family-testing-production.up.railway.app/

Эта копия развёртывается отдельно от GitHub. Отправка коммита в `origin/main` сама по себе не обновляет сайт: источник Railway сейчас — пакет, загруженный через CLI.

По запросу пользователя на обновление Railway запустите из корня `D:\Meili GPT`:

```powershell
.\publish-railway.ps1
```

Сценарий обновляет пакет из текущего кода платформы и локально опубликованных страниц. В загрузку включаются только `Dockerfile`, `launch.py`, `railway.json`, `requirements.txt`, `study/`, `seed/`. Служебная папка `.local` и секреты не копируются. Перед загрузкой проверяются отсутствие пользовательских книг в базе и английские/казахские текстовые слои страниц 3–7 учебника. Учётные данные остаются в существующих переменных Railway и постоянном томе.

После отправки дождитесь `SUCCESS` нового развёртывания. Обновите вкладку сайта и проверьте EN/RU/KZ на опубликованных страницах. Успешная загрузка пакета ещё не подтверждает работу сайта. Развёртывание обновляет учебные материалы; отзывы пользователей и отдельные данные шлюза остаются на томе.

Шаблоны этой папки хранятся в Git. `railway-study/` и временные пакеты `.local/railway-uploads/` исключены из Git. Оригинальные проекты в `D:\Forma` не используются при публикации.
