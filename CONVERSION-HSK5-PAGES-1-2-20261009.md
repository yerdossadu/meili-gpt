# HSK5 — исходные страницы 1 и 2 учебника и WB

Учебник: `9b495a8351c6`, HSK5上, 198 страниц. WB: `1a3750a2f488`, HSK_5 workbook 1, 142 страницы. Обработаны только исходные страницы 1–2 каждого файла, включая обложки. Публикация: HSK5, отдельно учебник и рабочая тетрадь. Номера на платформе: с. 1 и с. 2.

## Общие изменения конвертера

- `book-platform.mjs`: определение уровня HSK и типа материала из названия книги. Явные настройки книги имеют приоритет. Новая книга HSK5 больше не получает молча HSK1. Неизвестный материал требует явных настроек.
- `display-ocr.mjs`: дополнительный OCR уменьшенных изображений для крупных букв и номера тома, включая контрастный нижний фрагмент. Старый кэш обложки без этого шага повторно проверяется.
- `cover-volume.mjs`: пропущенный отдельный знак тома сверяется с распознанной обложкой того же PDF и отдельным компактным компонентом. На WB2 восстановлен «上», проверенный по исходному скану. Это восстановление из контекста, а не уверенный ответ OCR; происхождение записано в sourceEvidence.
- `cover-page.mjs`: надписи — выделяемый текст SVG, не растровая подложка. Буквы HSK и знаки номера имеют отдельные рамки. CSS строит цветные поля и полосы, логотипы сохраняются отдельными изображениями. Принадлежность OCR-строк проверяется по содержимому, чтобы большой блок не захватывал авторские подписи.
- Цвета читаются из исходной палитры, а не из контрастной сегментационной карты: это сохраняет светло-серый фон. Полосы и авторские поля измеряются по пикселям. Размер перевода адаптируется к выбранному языку без принудительного сжатия букв.
- Экспорт и копирование на рабочий стол поддерживают обе книги HSK5.

## Проверки и ограничения

111 тестов Webbook прошли. Все четыре страницы проверены в браузере в RU, EN, KZ и оригинале: незагруженных изображений и выхода текста за страницу не обнаружено. Публикация через локальную платформу проверена; переключение HSK5, учебник/WB и страниц 1–2 работает, KZ отображается. На обложках нет учебных списков новых слов; словарь страницы пуст, чужие слова HSK1 не переносятся.

PP-StructureV3 завершился аварийно (Windows access violation в детекторе текста) при первом запуске. Использован локальный PP-OCRv5 mobile, который завершил обработку; разметка и переводы проверены по сканам. Платные API не использовались. Смысловые поля и переводы подготовлены с проверкой человеком-ассистентом; геометрия и HTML строятся общими функциями. Полностью автономная семантическая обработка любых страниц этим результатом не доказана.

Точное совпадение 1:1 не объявляется: системные шрифты отличаются от печатных, растровая фактура цветных полей заменена CSS, некоторые мелкие декоративные отметки скана могут отличаться. Проценты сходства не считаются оценкой готовности. Интерфейс FS и платформы не перерабатывался; исходные проекты и Cloud не изменялись.

Проверки: `.codex/checks/hsk5-tests.txt`, `hsk5-published.json`, `hsk5-browser-final.json`. Скан каждого оригинала остаётся в локальной библиотеке, ревизии доступны для отката. Автономные копии: `approved-web-pages/hsk5-upper-textbook` и `approved-web-pages/hsk5-upper-workbook`, а также «web версии страниц» на рабочем столе. Следующий исходный номер — 3.
