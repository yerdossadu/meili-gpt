# Forma Studio — локальная мультимедиа-консоль

## Запуск

Нужен Node.js 22.15 или новее и FFmpeg с FFprobe. На Windows возьмите ZIP-сборку **release essentials** со [страницы Windows-сборок FFmpeg](https://ffmpeg.org/download.html#build-windows), извлеките `ffmpeg.exe` и `ffprobe.exe` из папки `bin` в `.tools\ffmpeg\` внутри проекта. Forma обнаружит их автоматически. Можно также использовать любую установленную сборку из `PATH`.

В Windows откройте `start-forma-studio.bat`: он запускает локальные службы чтения PDF и OCR, затем саму Forma Studio. При первом использовании OCR модель PaddleOCR может скачать веса распознавания.

Для ручного запуска из PowerShell сначала запустите локальный обработчик PDF/OCR, затем Forma Studio:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start-pdf-renderer.ps1
node --use-system-ca server.mjs
```

Проверьте, что команды `ffmpeg -version` и `ffprobe -version` выполняются в этом PowerShell. Если Windows блокирует запуск FFmpeg из терминала Codex, запустите Forma из обычного PowerShell. Если FFmpeg распакован в отдельную папку, укажите пути перед запуском:

```powershell
$env:FFMPEG_PATH = "C:\путь\к\ffmpeg.exe"
$env:FFPROBE_PATH = "C:\путь\к\ffprobe.exe"
node --use-system-ca server.mjs
```

Флаг `--use-system-ca` позволяет Node.js использовать доверенные сертификаты Windows при подключении к OpenRouter.

Затем откройте <http://127.0.0.1:4174> и нажмите «Настроить ключ».

Ключ OpenRouter вводится в самой консоли, остаётся только в оперативной памяти локального процесса и удаляется после его остановки. Не публикуйте сервер в интернете: он рассчитан на личный компьютер и привязан только к `127.0.0.1`.

## Возможности

- Избранные модели помечаются звездой, поднимаются в начало списка и сохраняются в локальном хранилище браузера.

- Чат с каталогом текстовых моделей; прикрепление изображений, PDF, аудио и текстовых файлов.
- Генерация изображений через OpenRouter Images API с референсами.
- Видео через асинхронный API: автоматический выбор доступных моделей, начальный/конечный кадр, референсы, ожидание результата и скачивание MP4.
- Музыка через аудио-модели с возможностью прослушать и скачать результат. Аудиофайл можно загрузить в видео-задание как референс, если это поддерживает выбранный провайдер.
- Распознавание и перевод аудиодорожки; выгрузка SRT/TXT или отдельной TTS-дорожки.
- Перевод видео до 20 секунд: загрузка MP4/MOV/M4V/WebM/MKV до 80 МБ, локальное извлечение аудио через FFmpeg, распознавание с таймкодами через OpenRouter, перевод реплик и сборка MP4 с субтитрами, без вшитых субтитров или с переводной TTS-дорожкой. При выключении обеих дорожек субтитров MP4 собирается без текста в кадре, а перевод доступен отдельным TXT. В двуязычном режиме отдельные стили задают 72 для русского текста и 96 для китайского. Для моделей с поддержкой голосового референса можно загрузить короткий образец голоса; Forma сверяет поддержку через каталог OpenRouter. Опционально локальный Demucs отделяет речь и сохраняет музыкальный/окружающий фон, FFmpeg регулируемо сводит дорожки. Готовый MP4 и выбранные текстовые дорожки скачиваются отдельно.

### Сценарная студия HSK Alternative

В разделе «Сценарии HSK» можно спланировать сериал по уровням: редактировать замысел и персонажей, добавлять серии и сцены, записывать учебные цели и целевые слова, сравнивать стандартную фразу с разговорным вариантом и вести диалоги с иероглифами, пиньинем и переводом. Сценарии сохраняются отдельно в браузере и экспортируются в JSON.

В отдельном разделе «Учебник HSK» PDF загружается один раз в локальное хранилище браузера. Текстовая модель OpenRouter анализирует весь документ и возвращает отдельные редактируемые карточки страниц, без ручного ввода диапазонов. Карточки включают содержание, учебную цель, героев и промпты для иллюстрации и короткого видео; можно добавить референсы и ключевые кадры, сгенерировать медиа и экспортировать страницы с результатами в интерактивный JSON. Для анализа PDF нужен совместимый с файлами/изображениями мультимодальный чат-модель. Весь PDF передаётся выбранной модели одним запросом; OpenRouter и провайдер могут устанавливать собственные ограничения размера, контекста и стоимости. Результаты, страницы и профили персонажей хранятся отдельно от проекта «Сценарии HSK».

## Ограничения

Возможности, допустимые длительности и форматы зависят от модели и провайдера OpenRouter. Для чата PDF и изображения передаются соответствующим мультимодальным API; неподдерживаемые типы файлов будут обозначены в сообщении.

Консоль сохраняет песни скачиванием на ваш компьютер, но не создаёт постоянную медиатеку. Для перевода видео FFmpeg и FFprobe должны быть установлены локально. Видео обрабатывается локально и хранится во временной папке ОС до завершения задачи; OpenRouter получает извлечённую аудиодорожку, текст и запрос синтеза речи, если включён режим озвучки. Тайминг озвучки генерируется одним фрагментом и может не совпадать с исходной речью посекундно. Выбранные модели и их провайдеры могут иметь ограничения по языкам, формату и тарифу; проверяйте их в каталоге OpenRouter.

### Голосовой референс и сохранение фона

Для сходства голоса включите «Использовать образец для сходства» и загрузите чистую запись голоса длиной до 20 секунд. Можно не загружать отдельную запись: при включённом разделении источником образца станет выделенная речь ролика. Голосовой образец и текстовый запрос синтеза отправляются выбранной модели OpenRouter. Это клонирование по референсу в рамках запроса, не постоянное обучение голоса. Возможность зависит от модели и выбранного провайдера; приложение проверяет `supports_voice_cloning` в каталоге OpenRouter.

Для сохранения музыки и фоновых звуков установите 64-битный Python, затем в PowerShell выполните `python -m pip install -U demucs soundfile`. Команда `demucs` должна быть доступна в той же среде, где запущен сервер Forma Studio. При необходимости задайте переменную `DEMUCS_PATH` с полным путём к `demucs.exe` перед запуском сервера. Перезапустите сервер и убедитесь, что на странице перевода написано, что Demucs найден. Модель Demucs скачивается при первом использовании, обработка на CPU может быть медленной. Разделение нейросетевое и не всегда идеально отделяет речь от музыки.

Используйте для клонирования только голос, на который у вас есть право и разрешение. В режиме сохранения фона локально создаются вокальная и инструментальная дорожки; OpenRouter получает дорожку речи для распознавания и/или образец для TTS.
# OCR-разметка сканированных страниц

Для сканов без текстового слоя Forma использует локальный PaddleOCR, чтобы получить текстовые строки и их координаты. Откройте `setup-ocr.bat` один раз, дождитесь установки CPU-версии PaddlePaddle и PaddleOCR, затем запустите Forma через `start-forma-studio.bat`. Первый запуск распознавания может скачать OCR-модели; они кэшируются в `.ocr-tmp`.

PDF рендерится локально через PDF.js, текст и координаты страницы извлекаются локальным PaddleOCR. Для перевода OpenRouter получает только распознанные текстовые фрагменты и их координаты; исходная страница туда не отправляется. Координаты остаются от OCR и сохраняются в данных страницы.
# Автоматическая HTML/CSS-копия страницы

В мастерской учебника кнопка «Сверстать страницу по PNG» запускает для выбранной страницы:

1. Локальный рендер PDF в PNG и OCR (готовый OCR используется повторно).
2. Разметку текста и CSS-областей выбранной Vision-моделью через OpenRouter.
3. Отрисовку редактируемого HTML и получение изображения именно этого DOM.
4. До двух проходов коррекции координат/цветов/типографики и заключительную проверку моделью.
5. Сохранение черновика, замечаний и стоимости в данных этой страницы.

Полная PNG-страница не является фоном HTML-клона. Иллюстрации вырезаются отдельными изображениями. Китайский сохраняется; пиньинь скрыт в клоне. Модель не получает API-ключ в промпте, другие страницы книги или данные других проектов.

«Применить клон» сохраняет результат, сохраняя предыдущую версию. Повторная сборка того же PNG открывает сохранённый результат без нового анализа; «Сравнить и исправить через ИИ» явно запускает ещё одну платную проверку. При обрезанном ответе или ошибке проверки сохранённая страница не заменяется. Оценка Vision не является измерением процента пиксельного совпадения; замечания могут потребовать ручной доводки. Страница 16 сохраняет ранее подготовленный отдельный шаблон.
