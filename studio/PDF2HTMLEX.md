# PDF → Web с исходным дизайном

В локальной студии http://127.0.0.1:4180/ откройте **PDF → Web**.
Выберите книгу или загрузите PDF существующей кнопкой «Загрузить PDF».
В панели **Веб-версия с исходным дизайном** конвертируйте текущую страницу
или укажите диапазон «От» / «До».

После завершения доступны сравнение с первой исходной страницей, открытие HTML
и скачивание ZIP. Распакуйте весь ZIP в одну папку и откройте `index.html`.
Архив содержит CSS, шрифты, изображения, скрипты просмотра и сведения об исходнике.
Кнопки «−», «+», «По ширине» изменяют масштаб без перестройки макета.

Результаты находятся в `studio/library/<книга>/pdf-layout/<задание>/`.
Каждая конвертация создаёт новое задание. Исходный PDF и результаты прежнего
OCR/ИИ-конвейера конвертер не перезаписывает. Задания выполняются по очереди,
история сохраняется после перезапуска FS. Незавершённое задание после
перезапуска помечается ошибкой; его можно запустить повторно.

Сканированный PDF остаётся изображением: выделяемого текста и редактируемых
учебных блоков в нём не появляется. PDF с текстовым слоем переносит текст и
шрифты. Автоматическое распознавание, переводы и учебные интерактивные блоки
остаются в прежнем конвейере. Макет сохраняет пропорции печатной страницы;
на узком экране используется масштабирование, а не перестановка элементов.

## Локальная установка

Конвертер уже установлен в `.tools/pdf2htmlEX/`. Для восстановления установки
запустите `setup-pdf2htmlEX.ps1` из папки studio, затем корневой
`restart-studio.ps1`. Эти скрипты работают только с данной копией проекта.
Можно указать другой совместимый исполняемый файл через `PDF2HTMLEX_PATH`.

Использована Windows-сборка 0.14.6, опубликованная Steven Lee и указанная
в [официальной старой странице загрузок](https://github.com/pdf2htmlEX/pdf2htmlEX/wiki/Download-Old-Information).
Источник: https://soft.rubypdf.com/software/pdf2htmlex-windows-version
Архив: https://soft.rubypdf.com/download/pdf2htmlex/pdf2htmlEX-win32-0.14.6-with-poppler-data.zip
SHA-256: `E92AA55699C3E9D9B4B4954BEA157E59B5C3363CBE9A7713495C553544026354`.
Это старая Windows-сборка; совместимость проверена на локальных учебниках
и текстовом тестовом PDF, а не на всех возможных PDF.
Лицензия конвертера GPLv3; поставляемые лицензии сохранены в его каталоге.

## Проверка и откат

Проверены страницы 16–17 учебника и рабочей тетради, сравнение с оригиналом,
сохранение текста и WOFF-шрифтов на `basic_text.pdf`, целостность ZIP,
ошибочные диапазоны и восстановление истории после перезапуска.
Автоматические проверки: `node --test studio/webbook/pdf-layout.test.mjs`
из корня проекта после установки конвертера.

Для отключения нового режима запустите корневой `rollback-pdf2htmlEX.ps1`.
Он сохраняет текущие файлы в резервную папку и возвращает прежний интерфейс FS;
исходные книги и результаты конвертаций остаются в библиотеке.
Перед изменением создана Git-метка `fs-before-pdf2htmlex-2026-10-05`.

При проверке обнаружено старое поведение FS: открытие книги из пустого браузера
очищало сохранённых персонажей. Добавлена защита от такой синхронизации.
Персонажи и их отображение в локальных страницах восстановлены из имеющейся
резервной копии `studio-before-three-ai`; эта защита сохраняется при откате.
