# Фонетика рабочей тетради, страница PDF 4

`workbook-page4.json` хранит отдельные инициали и финали, их тип и положения
в исходной таблице. Их можно выбрать мышью или клавиатурой и прослушать.
Картинка таблицы сохраняет печатный макет; текстовые кнопки добавляют действия.
Данные подключаются при каждой пересборке, экспорте и подготовке публикации.

В режиме «Оригинал» страница показывает исходный скан и отдельный выделяемый
OCR-текст. Распознавание может содержать ошибки; оно не заменяет проверку текста.
Русский и казахский остаются текстовыми слоями учебных блоков.
Точное изображение оригинала не означает автоматической точности верстки перевода.

https://github.com/cmguo/PinYinSound (`master`, 5 октября 2026).

без озвучивания латинских букв через английский голос.
В репозитории не указана лицензия; файлы используются в данной локальной копии.
