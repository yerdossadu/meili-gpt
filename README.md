# Meili GPT

Отдельный локальный проект для улучшений, создан 5 октября 2026 года.

- `study/` — копия `D:\Forma\GitHub\chao-hsk-study`.
- `studio/` — актуальная рабочая копия Forma Studio из `C:\Users\finecompKZ\Documents\Codex\2026-09-27\new-chat\outputs`, с OpenRouter, Alibaba Model Studio и OpenAI. Библиотека скопирована из `D:\Forma\library`.
- `data/study/` — независимая копия локальной библиотеки платформы из `D:\Forma\chao-data`.
- `COPY-MANIFEST.json` — SHA-256 всех файлов, проверенных сразу после копирования, до смены названия и локальных настроек.
- `STUDIO-COPY-MANIFEST.json` — проверка переноса актуальной студии с тремя AI-провайдерами. Предыдущая копия сохранена в `.local/backups/studio-before-three-ai`.

Запуск: двойной щелчок по `start-meili-gpt.bat`.
Платформа: http://127.0.0.1:8010, студия: http://127.0.0.1:4180.
Остановка: `powershell -ExecutionPolicy Bypass -File .\stop-meili-gpt.ps1`.

Для загрузчика `/manage` используется логин `teacher`. Отдельный локальный пароль и токен публикации создаются при первом запуске в `.local/settings.json` и не включаются в Git. Студия настроена на локальную платформу; при запуске её токен берётся из этого файла.

Исходные проекты и Cloud не изменяются. Этот проект использует собственный Git без удалённого репозитория, собственные порты, файлы и данные. Серверы слушают только 127.0.0.1. Папки данных, библиотека, окружение и секреты исключены из Git, но остаются на диске внутри Meili GPT.

AI-функции по-прежнему требуют настройки провайдеров; API-ключи из Cloud не переносились. Интернет также используется для исходных внешних шрифтов. OCR требует отдельной установки через `studio/setup-ocr.bat`; его окружение из исходной студии не переносилось.

Локальная Python-среда: `.venv`. Для восстановления установите Python, создайте `.venv` и установите зависимости из `study/requirements.txt`. Node.js используется из установленного локального окружения или PATH.
